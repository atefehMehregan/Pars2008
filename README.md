# 2008Pars — فروشگاه قطعات پژو ۲۰۰۸

فروشگاه اینترنتی قطعات یدکی پژو ۲۰۰۸، فارسی و راست‌به‌چپ.

> **وضعیت: فاز ۰ — پایه فنی.**
> فروشگاه هنوز ساخته نشده است. این مخزن فعلا فقط شالودهٔ امن پروژه است:
> پیکربندی، اتصال پایگاه داده، مهاجرت‌ها، پایه Express، قالب راست‌به‌چپ،
> پردازش تصویر و آزمون‌های پایه.

## پشته فنی

| لایه | انتخاب |
|---|---|
| اجرا | Node.js ۲۰/۲۲ LTS |
| وب | Express 5 |
| قالب | Nunjucks (رندر سمت سرور) |
| پایگاه داده | PostgreSQL (تنها گزینه — SQLite پشتیبانی نمی‌شود) |
| تصویر | sharp |
| رمز عبور | Argon2id (فاز احراز هویت) |
| اسکریپت سمت کاربر | جاوااسکریپت ساده، بدون فریم‌ورک |

## راه‌اندازی

```bash
npm install
cp .env.example .env      # سپس مقدارها را پر کنید
npm run migrate           # نیازمند یک PostgreSQL در دسترس
npm run dev
```

بررسی سلامت:

```
GET /health       سرویس بالاست؟
GET /health/db    پایگاه داده در دسترس است؟
```

## دستورها

| دستور | کار |
|---|---|
| `npm start` | اجرای سرویس |
| `npm run dev` | اجرا با بارگذاری دوباره |
| `npm run migrate` | اجرای مهاجرت‌های اجرانشده |
| `npm test` | آزمون‌های پایه |
| `npm run check:sharp` | تأیید کارکرد پردازش تصویر روی این محیط |

## ساختار

```
src/
  app.js            ساخت برنامه Express
  server.js         راه‌اندازی و خاموشی تمیز
  config/           تنظیمات، همه از متغیر محیطی
  db/               اتصال PostgreSQL و اجرای مهاجرت
  middleware/       امنیت، CSRF، محدودیت نرخ، اعتبارسنجی آپلود
  routes/           مسیرهای HTTP
  controllers/      (خالی — فاز بعد)
  services/         قالب‌بندی فارسی، پردازش تصویر
  views/            قالب‌های Nunjucks
public/             دارایی‌های عمومی (CSS، JS، تصویر ایستا)
storage/            ← بیرون از webroot، هرگز در Git
  originals/        تصویر اصل، خصوصی
  products/         مشتق‌های واترمارک‌خورده، عمومی از راه /media/products
  receipts/         رسید پرداخت، خصوصی، فقط با احراز هویت
migrations/         فایل‌های SQL شماره‌دار
scripts/            ابزارهای کمکی
tests/              آزمون‌ها (node:test)
```

## قاعده‌های پروژه

**پول.** مبلغ‌ها به **تومان** و به‌صورت `BIGINT` ذخیره می‌شوند. رشتهٔ
فارسیِ قالب‌بندی‌شده هرگز در پایگاه داده نمی‌رود — چون نه جمع‌پذیر است، نه
مرتب‌شدنی. تبدیل فقط در لحظه نمایش، با `formatToman()`.

**ارقام.** ورودی کاربر پیش از اعتبارسنجی با `toEnglishDigits()` نرمال
می‌شود؛ خروجی با `faDigits()` فارسی می‌شود.

**زمان.** `TIMESTAMPTZ` و UTC در پایگاه داده؛ نمایش شمسی با `formatJalali()`.

**فایل‌های آپلودی.** هرگز بایت خام کاربر ذخیره نمی‌شود. هر تصویر با sharp
دوباره رمزگذاری می‌شود، نامش UUID تصادفی است، نوعش از روی بایت‌های ابتدایی
تشخیص داده می‌شود (نه پسوند)، و `storage/` بیرون از webroot است.

**SQL.** فقط کوئری پارامتری (`$1`, `$2`). چسباندن مقدار داخل رشتهٔ SQL ممنوع.

**رازها.** هیچ رمز، کلید یا رشتهٔ اتصالی داخل کد یا Git نیست. فقط `.env`،
که در `.gitignore` است.

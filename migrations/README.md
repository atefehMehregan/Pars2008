# مهاجرت‌ها

فایل‌های SQL شماره‌دار که به ترتیب نام اجرا می‌شوند و هر کدام دقیقا یک بار.

قاعده‌ها:

* نام‌گذاری: `001_توضیح_کوتاه.sql`، `002_...` — شماره سه‌رقمی، ترتیب مهم است.
* هر فایل داخل یک تراکنش اجرا می‌شود؛ یا کامل اعمال می‌شود یا هیچ.
* **فایلی که یک بار اجرا و commit شد هرگز ویرایش نمی‌شود.** برای تغییر،
  فایل تازه بسازید.
* فایل‌های اجراشده در جدول `schema_migrations` ثبت می‌شوند.

اجرا:

```bash
npm run migrate
```

اسکیمای کسب‌وکار (محصول، دسته، برند، سفارش، پرداخت و ...) هنوز نوشته نشده
است؛ در فاز بعد و پس از تأیید طراحی پایگاه داده اضافه می‌شود.
